# Payroll Management CRUD API

A Spring Boot-based RESTful CRUD backend for managing employees.

## Features
- Create, Read, Update, Delete Employees
- In-memory H2 database
- Swagger UI for API documentation

## Tech Stack
- Java 17
- Spring Boot
- Maven
- H2 Database
- Swagger (SpringDoc OpenAPI)

## Running the Project
```bash
mvn spring-boot:run
